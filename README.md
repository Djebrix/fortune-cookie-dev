One original line of fortune-cookie wisdom for a software developer, about the
quiet courage of deleting code. It says something every developer knows from
experience — dead code is a liability, not an asset — and turns it around: the
safest feature you will ever ship is the one you remove.

> "The code you delete today is the only feature that can never break in production."

`main.py` (Python 3 standard library only) writes the line to `entry.txt` in
`ENTRY_OUTPUT_DIR` (default `/output`), asserting it is 1–120 characters.
